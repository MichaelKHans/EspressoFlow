# Lokale Videoer & Tunge Mediefiler

Denne mappe er beregnet til dine egne lokale videofiler, testoptagelser, OCR-kalibreringsklip og demonstrationsvideoer.

### 🔒 Sikkerhed & Størrelse
- **Ikke i Git / GitHub:** Alt indhold i denne mappe (undtagen denne `README.md`) er tilføjet til `.gitignore`. Dine store videofiler bliver **aldrig** skubbet til GitHub.
- **Ikke i App-bundlet:** Mappen ligger uden for `src/` og `public/`, hvilket betyder at Vite, Vercel og Capacitor **aldrig** inkluderer videoerne i selve appen eller mobil-buildet.
